# dsh-github

DSH 侧边栏 GitHub 插件：在 dsh-better-sidebar（≥ 0.12.0）中注册一个 **GitHub Inbox** tab——收件箱未读通知 + 角标、类别过滤（CI 默认隐藏）、已读/Done、Approve / Request changes / Comment、门控 Merge。

**状态**：v0.1.0 开发中（见 docs/plans/）。
